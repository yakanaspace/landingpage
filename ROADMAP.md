# Yakana Space — Roadmap

This document outlines the development milestones for **Yakana Space**, an open-source, decentralized platform connecting science communicators, research institutions, and the public.

Inspired by the Andean dark constellation **Yakana**, our goal is to map, validate, and amplify scientific outreach worldwide. For a visual, filterable view of these milestones, visit the interactive `roadmap.html` page on our site.

---

## Status Legend

- `[x]` **Completed** — Live in production or merged into `main`
- `[-]` **In Progress** — Actively being designed or built
- `[ ]` **Planned** — Scoped for upcoming milestones

---

## Phase 1: Foundation & Public Presence

Establishing the project identity, open-source governance, and static web infrastructure.

- [x] Define project vision, philosophy, and Andean **Yakana** astronomical identity
- [x] Publish minimalist dark-mode landing page (`index.html`) with bilingual (EN/ES) support
- [x] Add interactive roadmap page (`roadmap.html`) and custom astronomical error page (`404.html`)
- [x] Configure static deployment on Cloudflare with custom 404 routing (`wrangler.jsonc`)
- [x] Integrate privacy-friendly traffic metrics via Cloudflare Web Analytics
- [x] Establish repository documentation (`README.md`) under the **GNU GPL-3.0** license
- [-] Link `roadmap.html` across site navigation and finalize initial community guidelines (`CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`)

---

## Phase 2: Core Platform & Outreach Directory

Transitioning from a static presence to an interactive, community-driven hub.

- [ ] Design open database schema and core API architecture
- [ ] Build the **Interactive Map** of science communicators, observatories, museums, and outreach collectives
- [ ] Launch the **Community Event Calendar** for talks, star parties, workshops, and science festivals
- [ ] Implement contributor profiles for independent communicators and research institutions
- [ ] Enable open project & event submission workflows with basic moderation

---

## Phase 3: Peer-Validation System

Ensuring scientific rigor and transparency in public science communication.

- [ ] Build the **Scientific Script & Material Submission** portal
- [ ] Implement a structured **Peer-Validation Workflow** for reviewing scripts, references, and claims
- [ ] Create transparent revision histories and source-citation tracking
- [ ] Introduce verified reviewer roles and domain-specific review tags (e.g., Astronomy, Biology, Physics, Earth Sciences)

---

## Phase 4: AI-Powered Indexing & Discovery

Making verified scientific outreach effortless to search, cross-reference, and translate.

- [ ] Deploy **AI-Powered Semantic Search** across validated scripts, events, and projects
- [ ] Add automated topic clustering, keyword extraction, and cross-disciplinary recommendations
- [ ] Integrate AI-assisted multilingual indexing to bridge Spanish, English, and regional outreach communities
- [ ] Build citation and source-checking assistants to support peer reviewers

---

## Phase 5: Decentralization & Ecosystem Scale

Expanding long-term resilience, interoperability, and community governance.

- [ ] Release a documented **Public API** and open datasets for researchers and educators
- [ ] Explore federated/decentralized node architecture for institutional and regional mirrors
- [ ] Establish formal partnerships with universities, science museums, and open-science networks
- [ ] Transition to a transparent, community-led governance model

---

## How to Contribute

Yakana Space is built in the open. If you want to propose a feature, report an issue, or help build any of the phases above:

1. Check existing issues or open a new discussion on [GitHub](https://github.com/yakanaspace).
2. Follow updates and community calls on [Instagram](https://www.instagram.com/yakana.space).
